Daily discovery
Use the included Windows scheduling script from the project folder.
./discovery_mvp/schedule.ps1 `
  -Python "$PWD/.venv/Scripts/python.exe" `
  -At '09:00' -QueryBudget 8
Runs daily at 09:00 in the computer’s timezone while you’re logged on. Each completed run refreshes the live workspace. This panel does not install or verify a schedule.
